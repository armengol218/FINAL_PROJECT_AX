# FINAL_PROJECT_AX

Projecte final d'Arquitectura de Xarxes.

## Objectiu
Demostrar un atac Man-in-the-Middle (MITM) mitjançant ARP Spoofing.

## Tecnologies utilitzades
- Mininet
- Python
- Scapy
- Flask

## Components
- h1: Banc
- h2: Client
- h3: Atacant

## Resultat
L'atacant intercepta una transferència HTTP i modifica l'import de 100 EUR a 1000 EUR.
